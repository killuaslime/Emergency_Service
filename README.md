# ⚡ Emergency Service Bot

Telegram-подобный бот для платформы **MAX**, предназначенный для автоматизации контроля электроснабжения в магазинах.

Бот позволяет сотрудникам сообщать об отключениях электроэнергии, супервайзерам отслеживать состояние магазинов и получать автоматические ежедневные сводки.

## 🚀 Возможности

### 🏪 Управление магазинами
- Регистрация сотрудников магазинов.
- Привязка пользователей к конкретным магазинам.
- Индивидуальная панель управления для каждого магазина.
- Управление состоянием электроснабжения.

### ⚡ Контроль электроэнергии
- Фиксация отключения электроэнергии.
- Фиксация восстановления электроснабжения.
- Автоматический расчёт продолжительности отключения.
- Сохранение истории отключений в базе данных SQLite.

### 🌅 Утренний опрос
Ежедневно в **08:15 по московскому времени** каждому зарегистрированному магазину отправляется опрос:

- 🟢 Есть свет
- 🔴 Нет света

Если сотрудник выбирает «Нет света», бот фиксирует начало отключения с 08:15.

Если сотрудник выбирает «Есть свет», бот при необходимости закрывает ранее зарегистрированное отключение временем 08:15.

В **08:30** бот отправляет общую сводку в рабочую группу:

- 🔴 Магазин открылся без электроэнергии.
- 🟢 Магазин открылся с электроэнергией.
- ⚪ Магазин не ответил.

### 🌙 Вечерняя сводка
Ежедневно в **22:10** бот отправляет отчёт о состоянии электроснабжения магазинов.

- 🟢 Закрыт с ЭЭ.
- 🔴 Закрыт без ЭЭ.

Статус определяется по фактическому состоянию записей об отключениях в базе данных.

### 👨‍💼 Панель супервайзера
- Просмотр закреплённых магазинов.
- Контроль состояния электроснабжения.
- Просмотр истории отключений.

## ⚙️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/killuaslime/Emergency_Service.git
cd Emergency_Service
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация на Windows:

```bash
venv\Scripts\activate
```

Активация на Linux:

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта и укажите необходимые параметры:

```env
BOT_TOKEN=your_bot_token
GROUP_CHAT_ID=your_group_chat_id
```

Не публикуйте `.env` и токены в открытом доступе.

### 5. Подготовка данных

Создайте необходимые файлы конфигурации магазинов и супервайзеров в соответствии с форматом проекта.

При первом запуске бот инициализирует базу данных SQLite.

### 6. Запуск

```bash
python main.py
```

## ⏰ Расписание автоматических задач

| Время (Москва) | Действие |
|---|---|
| 08:15 | Отправка утренних опросов |
| 08:30 | Общая утренняя сводка |
| 22:10 | Вечерняя сводка |

## 🗄 База данных

Для хранения информации используется SQLite.

Основные таблицы:

- `shops` — магазины и их настройки.
- `users` — пользователи и их роли.
- `registration_requests` — заявки на регистрацию.
- `outages` — история отключений электроэнергии.
- `daily_checks` — результаты утренних опросов.
- `daily_summary_log` — журнал отправки сводок.
